# 🚀 Yash's 3D Portfolio

Welcome to my personal 3D portfolio repository! This project showcases my skills in modern web development, particularly in creating immersive, interactive 3D web experiences.

## 🌟 About the Project

This portfolio is a highly engaging personal website that features animated 3D scenes, smooth camera transitions, interactive model showcases, and a responsive design. It demonstrates my ability to blend creative design with robust technical implementation to build standout digital experiences.

## ⚙️ Tech Stack

- **Three.js & React Three Fiber:** For rendering and managing 3D graphics in a React environment.
- **Drei:** Helpful helpers for react-three-fiber.
- **GSAP:** For high-performance, smooth scroll interactions and animations.
- **Tailwind CSS:** For rapid UI development and responsive styling.
- **React 19:** Building the user interface.
- **Vite:** Next-generation, fast frontend tooling.

## 🔋 Key Features

- **Interactive 3D Environments:** Animated 3D models and dynamic reveal animations.
- **Immersive Visuals:** Realistic lighting, shadows, and smooth camera movements.
- **Scroll-Triggered Animations:** GSAP-powered scroll interactions for a seamless user experience.
- **Responsive Layouts:** Carefully crafted with Tailwind CSS to ensure it looks great on both desktop and mobile devices.
- **Contact Integration:** Functional contact form powered by EmailJS.

## 🤸 Getting Started

If you want to run this project locally, follow the steps below:

### Prerequisites

Make sure you have the following installed on your machine:
- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/en)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SYZdevloper/3d-portfolio.git
   cd 3d-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root of the project and add your EmailJS credentials:
   ```env
   VITE_APP_EMAILJS_SERVICE_ID=your_service_id
   VITE_APP_EMAILJS_TEMPLATE_ID=your_template_id
   VITE_APP_EMAILJS_PUBLIC_KEY=your_public_key
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173/) in your browser to view the project.
